# 📊Calculadora de Média
> Aplicação web simples desenvolvida para calcular a média de notas e exibir a situação do aluno com base no resultado.
## 🚀 Funcionalidades

- Entrada de notas numéricas
- Cálculo automático da média
- Validação de campos vazios
- Exibição formatada do resultado
- Classificação da situação:
- ✅ Aprovado
- ⚠️ Recuperação
- ❌ Reprovado
